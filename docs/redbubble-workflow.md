# Redbubble Upload Workflow

ZeroPOD should use Redbubble's **Copy Existing Work** option as the baseline workflow.

## Intended sequence

1. Open Redbubble using the saved local ZeroPOD browser session.
2. Open the **Copy Existing Work** flow.
3. Select the **first existing work** as the baseline template.
4. Preserve the baseline product configuration, placement, scale, enabled products, and other product settings unless ZeroPOD explicitly needs to change them.
5. Replace the main artwork with the approved ZeroPOD final PNG.
6. Replace the listing details with the generated metadata:
   - Title
   - 1 Main Tag
   - 14 Supporting Tags
   - Short Description
7. Review the copied work for required/changed fields.
8. Save or publish the copied work.

This baseline-copy approach is preferred over creating a brand-new work from scratch because it preserves the user's known-good Redbubble product configuration.
